# TokTickIT

TokTickIT is a React, Express, PostgreSQL, and Prisma IT service-desk application. Lab 4 adds auditable Actions Taken, controlled Ticket resolution, role dashboards, final regression coverage, and responsive accessibility improvements.

The maintained application workspace is [`toktickit/`](toktickit/).
